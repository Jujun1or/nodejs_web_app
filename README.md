# Система управления складом (Warehouse Management System)

Веб-приложение для автоматизации учета товаров на складе с поддержкой многопользовательского режима и разграничением прав доступа.

## Возможности

**Управление товарами и категориями:**
- Добавление, редактирование, удаление товаров
- Категоризация товаров
- Указание мест хранения (location)
- Контроль минимального остатка

**Складские операции:**
- Регистрация приходных операций (поступление товара)
- Оформление расходных операций (отгрузка)
- Автоматическое обновление остатков
- Журнал всех операций с историей

**Поиск и фильтрация:**
- Поиск товаров по названию
- Фильтр по категории и местоположению
- Отображение товаров в наличии/отсутствии
- Выделение товаров с критическим остатком

**Отчеты:**
- Текущие остатки всех товаров
- Товары с остатком ниже минимального
- Операции за выбранный период
- Движение конкретного товара
- Экспорт отчетов в CSV

## Веб-интерфейс

Приложение предоставляет интуитивный интерфейс с ролевой моделью:

**Для администратора:**
- Полное управление товарами и категориями (CRUD)
- Просмотр всех отчетов
- Управление пользователями (через БД)

**Для кладовщика:**
- Просмотр товаров и остатков
- Регистрация приходных/расходных операций
- Формирование отчетов

**Интерфейс включает:**
- Дашборд с быстрым доступом к модулям
- Таблицы с сортировкой и фильтрацией
- Формы для операций с валидацией
- Индикаторы критических остатков

## Стек технологий

**Бэкенд:**
- Node.js
- Express 4.18.2 — веб-фреймворк
- express-session + connect-sqlite3 — управление сессиями
- body-parser — обработка запросов

**База данных:**
- SQLite3 с WAL-режимом для производительности
- Хранение: товары, категории, операции, пользователи, сессии

**Фронтенд:**
- HTML5, CSS3
- JavaScript (vanilla)
- Адаптивный дизайн

## Быстрый старт

### Предварительные требования
- Node.js 16.x или выше

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Jujun1or/nodejs_web_app.git
cd nodejs_web_app

# Установить зависимости
npm install

# Создать папку для базы данных
mkdir data

# Инициализировать базу данных с тестовыми данными
node init-db.js

# Запустить приложение
